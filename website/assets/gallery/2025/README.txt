Drop AFCON NT 2025 photos in THIS folder.

- Accepted types: .jpg .jpeg .png .webp
- Any filenames are fine (e.g. final-whistle.jpg, DSC_0421.jpg).
- For best quality/size, export longest edge ~1600px.

After adding or removing photos, regenerate the gallery manifest by
running this once from the project root:

    powershell -File website/build-gallery.ps1

(or just tell Claude "rebuild the gallery" and it will run it for you).
